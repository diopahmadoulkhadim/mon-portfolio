# Portfolio - Ahmadoul Khadim Diop

Portfolio personnel de **Ahmadoul Khadim Diop** réécrit avec **React 18**, **TypeScript**, **Vite** et **Bootstrap 5**.

## Fonctionnalités

- **Navigation fluide et interactive** : Navbar fixe avec détection de défilement, espionnage de section active et menu mobile responsive.
- **Thème sombre / clair** : Bascule dynamique avec persistance dans le `localStorage`.
- **Texte animé dactylographié** : Affichage dynamique des titres et vocations ("Développeur Web", "Créateur de contenu", "Entrepreneur", "Passionné du numérique").
- **Section Présentation & Compétences** : Barres de progression stylisées avec gradients.
- **Projets réalisés** : Cartes interactives avec dégradés visuels distincts, badges et liens externes vers les déploiements de démonstration.
- **Formulaire de contact** : Validation en temps réel et notification de succès conviviale sans rechargement de page.
- **Téléchargement de CV** : Lien direct vers le CV en format PDF.

## Technologies

- React 18
- TypeScript
- Vite
- Bootstrap 5 & Bootstrap Icons

## Déploiement sur GitHub Pages

Le workflow GitHub Actions situé dans `.github/workflows/deploy.yml` compile le site et publie automatiquement le dossier `dist` à chaque push sur `main` ou `master`.

Dans le dépôt GitHub, ouvrez **Settings > Pages** et sélectionnez **GitHub Actions** comme source de déploiement. Le lien Pages s’affichera dans cette même page lorsque le workflow aura terminé.
