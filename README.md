# Portfolio - Ahmadoul Khadim Diop

Portfolio personnel d’**Ahmadoul Khadim Diop**, réalisé en HTML, CSS et JavaScript natifs avec Bootstrap 5.

## Fonctionnalités

- **Navigation fluide et interactive** : Navbar fixe avec détection de défilement, espionnage de section active et menu mobile responsive.
- Présentation, compétences, projets, parcours et coordonnées.
- Mise en page responsive inspirée de la maquette fournie.
- Navigation Bootstrap 5 et interactions JavaScript natives.
- Accès direct au CV PDF et contact par e-mail ou WhatsApp.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

GitHub Pages sert directement `index.html` depuis la racine du dépôt. Les fichiers CSS, JavaScript et images sont référencés par des chemins relatifs pour rester accessibles sur le sous-dossier du site.
